# Módulo `usuarios`

Datos del médico que se imprimen en cada nota.

## Endpoints propuestos

Borrador para el contrato del 26 de noviembre. Backend lo confirma y lo documenta en `docs/api/`.

- `GET /api/usuarios/{id}`
- `PUT /api/usuarios/{id}`: nombre y cédula profesional
- `PUT /api/usuarios/{id}/contrasena`
