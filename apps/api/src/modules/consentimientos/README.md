# Módulo `consentimientos`

Una carta por tratamiento y la autorización de fotos, firmadas en la tablet.

## Endpoints propuestos

Borrador para el contrato del 26 de noviembre. Backend lo confirma y lo documenta en `docs/api/`.

- `GET /api/pacientes/{id}/consentimientos?tipo=`
- `POST /api/pacientes/{id}/consentimientos`: incluye la imagen de la firma
